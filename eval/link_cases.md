# Link test cases

For each article: links a good Link Researcher should suggest, links that
are acceptable but not required, and candidates it should reject even
though similarity ranks them high.

Standard: prefer same story coverage, then related stories and explainers.
A thematic link is only worth suggesting when it would genuinely help a
reader. Suggesting fewer links is better than forcing weak ones.

Acceptable:
- 26 Interest rates held but Bank signals rise if energy prices stay high (background)

Should reject:
- 43 Aviation faces hotter, stormier skies (surface match on disruption)
